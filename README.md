# 🧮 Calculadora Profesional

Calculadora web desarrollada utilizando HTML, CSS y JavaScript.

El proyecto utiliza una estructura organizada separando la interfaz,
los estilos y la lógica de programación.

## 🚀 Tecnologías

- HTML5
- CSS3
- JavaScript
- Diseño Responsive

## 📁 Estructura

```text
calculadora-profesional/
│
├── index.html
│
├── css/
│   └── styles.css
│
├── js/
│   └── calculator.js
│
└── README.md
````

## ✨ Funcionalidades

* Suma
* Resta
* Multiplicación
* División
* Números decimales
* Botón para limpiar
* Botón para borrar
* Manejo de división para cero
* Soporte para teclado
* Diseño responsive
* Interfaz moderna

## 💻 Ejecución

No necesita instalación.

Simplemente abre:

```text
index.html
```

con cualquier navegador web moderno.

También puedes utilizar Live Server desde Visual Studio Code.

## ⌨️ Atajos de teclado

| Tecla     | Función        |
| --------- | -------------- |
| 0 - 9     | Números        |
| +         | Suma           |
| -         | Resta          |
| *         | Multiplicación |
| /         | División       |
| Enter     | Calcular       |
| Backspace | Borrar         |
| Escape    | Limpiar        |
